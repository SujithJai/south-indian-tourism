# 🌴 South Indian Tourism (Mohanur, Namakkal)
### High-End Animated Cinematic Website with 4K Drone Footage

A modern, high-performance web platform built with **React 19 + Vite 8 + Tailwind CSS v4 + Lucide Icons** showcasing South Indian tourism with a primary focus on **Karnataka** & **Tamil Nadu**, live 4K drone video playback, organic green wave dividers, interactive packages, Shiva temple pilgrimage yatras, and instant WhatsApp booking.

---

## 🚀 How to Run Locally

```bash
# 1. Navigate to the project directory
cd south-indian-tourism

# 2. Run the development server
npm run dev
```

Open your browser and visit: `http://localhost:5173`

## 🌐 How to Push to GitHub & Deploy to Vercel

### Step 1: Create a GitHub Repository
1. Go to [github.com/new](https://github.com/new)
2. Create a new repository named `south-indian-tourism` (Public or Private).

### Step 2: Link and Push Code
```bash
git remote add origin https://github.com/<your-username>/south-indian-tourism.git
git branch -M main
git push -u origin main
```

### Step 3: Deploy to Vercel
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New Project"** -> **"Import"** `south-indian-tourism`.
3. Vercel will automatically detect **Vite** and configure the build command (`npm run build`) and output directory (`dist`).
4. Click **"Deploy"** — within 30 seconds your website will be live worldwide with a free `.vercel.app` domain and HTTPS!
